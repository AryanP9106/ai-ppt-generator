# ai-ppt-generator

A high-efficiency Python backend tool that automates presentation deck assembly using generative AI APIs and local system scripting.

## 🎯 Core Features

* **Automated Slide Assembly:** Translates structured text inputs directly into formatted PPTX layouts.
* **API Integration:** Handles dynamic asset generation and rate-limit parsing seamlessly.
* **Local Optimization:** Built for fast local terminal execution with clean error-handling.

## 🛠️ Tech Stack

* **Language:** Python 3.14
* **Core Libraries:** python-pptx, requests, threading
* **Environment:** Optimized on Linux / Local Sandbox Environments
